# ReHome - Final - DeepSeek + Meta AI

Full app: 5 files from DeepSeek + Pro/Auth + configs

## Run
```
npm install
npm run dev
```
Open http://localhost:3000

## Files
- lib/states.ts - all 50 states
- lib/pricing.ts - estimate engine SELL/FIX/DONATE
- app/page.tsx - main estimate
- app/marketplace/page.tsx - filterable marketplace
- app/earnings/page.tsx - earnings & CO2
- app/pro/page.tsx - Pro $19
- app/auth/page.tsx - Login

## Deploy to Vercel
Import this folder to GitHub, then import in Vercel.
